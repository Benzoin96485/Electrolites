## 已交付实现

- 对结构上不连接到局域输出的 canonical 边界，不分配无用的 GPU 零导数；
  deferred gather 的真实导数仍完整回传，显式请求的未使用宿主导数仍返回精确零。
- 在原有 16 GiB 私有池中，先用保守上界判断打包是否安全；空间不足时逐个输入
  累加并回传，避免同时持有全部导数副本及拼接缓冲。重复索引仍使用原 GPU
  散加顺序，不修改种子、原值或其他导数视图。三个开关默认关闭：
  `DLPNO_RESIDENT_CONNECTED_SOURCES`、`DLPNO_RESIDENT_COTANGENT_CHUNKED`、
  `DLPNO_RESIDENT_COTANGENT_FAST_GUARD`。本轮 61 项测试全部通过，无跳过；
  含真实 32 MiB 池下的旧路径失败复现、分块成功及 C/F 布局、重复和选定 VJP。

- T1 求解器可显式选择常驻分片中的副卡，默认仍为主卡。副卡分母副本和所有大向量
  在求解后释放，归约次序不变。MP2、CCSD 和参考态响应保持原设备配置。
- 检查点前向可省去反向记录，默认关闭；共享输入和读缓存的 canonical 叶节点保持
  可微状态，反向重放始终完整跟踪。当前完整小体系实际记录 234 个无记录前向区域、
  86013 条反向记录和 177 次逐字节验证的重放。

上述副卡求解与无记录前向联合配置先前的 53 项 GPU 测试全部通过、无跳过；包含前向/反向记录计数、
重复/选定/消耗式 VJP、输入不变性、重放漂移拒绝、精确单任务回退、映射输入，
以及副卡 GMRES 对独立 CPU 稠密参考解的比较。父版本另有 61 项测试通过，
不能将两批声称为一次 114 项测试。本次三次完整核梯度均覆盖全响应。

- 显式标记独占、互不重叠且不别名于种子/原值的源梯度缓冲，减少外层重复复制。
  普通视图及有别名的导数仍复制后累加；重复、选定和消耗式 VJP 保持有效。

- 局域源图逐块重建，保留不可变 FP64 输入和有上限的设备输入缓存。重建必须逐字节
  复现原始输出，再执行所有需要的系数导数，并释放临时图。
- MP2 使用局域秩分组、合并投影和直接重叠块；CCSD 使用紧凑索引、局域 DF
  检查点输出、不可变记录的平坦数据复用和连续伴随缓冲区。
- T1 转置作用分布到四张卡，按固定次序累积；λ 求解后释放 CUDA 捕获缓冲区，
  完整系数 VJP 仍执行。
- 超出填充工作区限制的单个三元组回退到精确无填充 GPU 公式；分组和单任务
  使用同一 2 GiB 限制，没有降低精度或改变截断。
- `DLPNO_RESIDENT_MMAP_INPUTS=1` 将足够大的不可变输入写入节点本地只读映射，
  供工作进程共享。当前阈值 `DLPNO_RESIDENT_MMAP_MIN_KIB=512`；最后释放所有
  工作进程输入后，主进程才清理映射文件。各进程 RSS 不可相加当作物理内存。
- `DLPNO_TRIPLES_COMPACT_PRIMAL=1` 只复制数值 T1 求解器实际需要的字段，避免
  在 T1 开始前复制全部 CCSD 张量及随后丢弃的重叠缓存。原 AD 状态、隐式残差
  及全部系数导数保留。

共享输入、精确回退与现有重建路径的 51 项测试，以及新增 T1 精简快照的 6 项

```python
if __name__ == "__main__":

    os.environ.pop("CONTRACT_ENGINE", None)

    os.environ["CUDA_VISIBLE_DEVICES"] = ",".join(devices)
    os.environ["OMP_NUM_THREADS"] = "1"
    os.environ["OPENBLAS_NUM_THREADS"] = "1"

    import pyscf.__config__ as pyscf_config
    pyscf_config.num_devices = 1
    # 在此构建并收敛 RHF/Boys LocalGPUDLPNO 对象 base，随后：
    gradient = base.nuc_grad_method(
```
